# Vibe-to-Spec Transmuter

[English](README.md) | [한국어](README.ko.md)

Vibe-to-Spec Transmuter는 아래 사용자를 위한 초보자 친화 요구사항 구조화 도구입니다.

- 비개발자
- 바이브코딩 초보자
- 비전공 학습자

막연한 아이디어를 구조화된 스펙으로 바꾸고, 기술 선택 가이드를 제공하며, 바로 전달 가능한 결과물을 생성합니다.

## 하는 일

1. 사용자가 자연어로 요구사항을 입력합니다.
2. AI가 표준 스키마 기반 구조화 결과를 생성합니다.
3. 탭별 화면에서 결과를 검토합니다.
   - 비전공자
   - 개발자
   - 기술 선택
   - 사고
   - 레이어
   - 용어
4. 프롬프트/개발 스펙 통합 화면에서 각각 복사해 활용합니다.

## 현재 주요 기능

### 1) 구조화 스펙 생성

- `standard_output` 고정 스키마 정규화
- 모델 JSON 파싱 실패 시 1회 자동 복구 재시도
- 산출물:
  - `artifacts.nondev_spec_md`
  - `artifacts.dev_spec_md`
  - `artifacts.master_prompt`
  - `layers.L1_thinking`
  - `glossary`

### 2) 하이브리드 기술 선택 안내

- 의사결정 프레임은 고정:
  - 옵션 A: 빠른 검증형
  - 옵션 B: 균형 성장형
  - 옵션 C: 확장 운영형
- 각 프레임 내부의 구체 스택 후보는 입력 기반 동적 추천
- 최종 순위는 앱 내부 점수식으로 결정론 계산:
  - 난이도 45
  - 비용 35
  - 확장성 20
- 제공 내용:
  - 5요소 프로필 추정(예산/기간/팀역량/사용자수/민감도)
  - 옵션 비교표
  - 최종 추천 + 차선안
  - 추천 반영 프롬프트 복사

### 3) 프롬프트 + 개발 스펙 통합 화면

- 탭 옆 빠른 버튼:
  - 프롬프트
  - 개발 스펙
- 한 화면에서 두 결과를 동시에 확인
- 각 패널 내부 복사 버튼 분리 제공

### 4) 사용 모델 드롭다운

- 헤더에서 사용 가능한 Gemini 모델 후보군을 드롭다운으로 표시
- 선택한 모델이 아래 두 호출에 반영:
  - 메인 구조화 생성
  - 하이브리드 스택 추천
- 선택이 없으면 기존 자동 선택(fallback) 흐름 유지

### 5) 용어 네비게이터

- flow stage 기반 용어 카드
- 초급/실무 모드 전환
- 본문 용어 칩 클릭 시 용어 카드 연동
- 용어 카드에서 본문 위치 찾기 지원

### 6) 학습 모드

- `ON`: 사고 탭 활성화(가정/질문/대안 비교)
- `OFF`: 사고 탭 비활성화 후 빠른 실무 확인 중심

## API 키 정책

- `sessionStorage`만 사용
- TTL: 30분
- 만료 시 자동 삭제 및 재입력 유도
- 과거 `localStorage` 키 자동 정리

## 보안 참고

현재는 교육용 MVP를 위한 클라이언트 직접 호출 구조입니다.

- AI 호출이 브라우저에서 수행됩니다.
- API 키는 브라우저 세션 범위에서 다뤄집니다.

운영 환경에서는 아래 전환을 권장합니다.

- 서버 프록시 구조
- 서버 보관 API 키
- 인증/레이트리밋/감사 로그 적용

## 프로젝트 구조

```text
src/

  index.css       # 테마, 마크다운/테이블 가독성 스타일
  main.jsx        # React 엔트리
```
